# Ampy Job Board

> Role: REFERENCE

Standalone paid-test workspace for Ampy Services. The product is a small operations board: browse 20 jobs, filter by status, search by customer, inspect a job, and save a team note.

## Delivery boundary

- `LOCAL`: Next.js app with demo fallback and Postgres query path.
- `BRANCH`: `josh/ampy-job-board`, local only.
- `STAGING`: not deployed.
- `PRODUCTION`: not deployed.
- `VERIFIED`: build and local smoke checks only; no real Postgres or signed-in walkthrough yet.
